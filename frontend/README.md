# Попутно

Клиентская часть сервиса совместных поездок. React, React Router, Vite, CSS, Leaflet и Lucide.

## Локальный запуск

Нужны Node.js 22.12+ или 24+ и pnpm 11.

1. Запустите PostgreSQL и Laravel по [инструкции бэкенда](../backend/README.md). Для проверки с готовыми данными выполните `php artisan db:seed --class=DemoRideSeeder`.
2. Из папки `frontend` выполните:

   ```sh
   pnpm install --frozen-lockfile
   pnpm dev
   ```

3. Откройте `http://127.0.0.1:5173`. Для кабинета водителя и проверки чата используйте разные браузерные сессии. Адреса и пароль демонстрационных аккаунтов указаны в инструкции бэкенда.

Vite проксирует `/api` в Laravel по адресу `http://127.0.0.1:8000`. При другом адресе скопируйте `.env.example` в `.env.local` и задайте `API_PROXY_TARGET`.

```sh
pnpm build
pnpm preview
```

Сборка находится в `dist/`. На сервере отдавайте статическую сборку и проксируйте `/api` в Laravel на том же origin. Leaflet использует тайлы OpenStreetMap. Линия и точки маршрута доступны при недоступности подложки.

## Структура

- `src/App.jsx` — навигация и маршрутизация.
- `src/pages/` — поиск, карточка поездки, брони, кабинет водителя, вход и профиль.
- `src/components/` — подсказки городов, карточки, карта, чат и запросы водителя.
- `src/services/` — общий Fetch-клиент, сессия с токеном Sanctum, загрузка данных и форматирование.
- `src/styles.css` — адаптивная сетка, формы и состояния интерфейса.
- `public/ural-road.webp` — обложка поиска, созданная в ImageGen. Запрос: «Аэрофотография извилистой асфальтовой дороги среди хвойных лесов и осенних берёз на Урале, дорога справа, тёмный лес слева».
